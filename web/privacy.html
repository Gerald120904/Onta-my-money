Política de privacidad de Onta My Money

Esta política describe el tratamiento de datos al usar Onta My Money y sus funciones de correo. La aplicación administra información financiera que cada usuario introduce, como cuentas, ingresos, gastos, metas y compromisos. Esa información se guarda localmente para permitir el uso sin conexión y, cuando se activa la sincronización, se transmite al backend y a su base de datos para mantener los dispositivos del usuario sincronizados.

Correo del sistema y Google

Una cuenta administradora autoriza Google OAuth para que el backend envíe mensajes de verificación de cuenta, recuperación de contraseña y avisos de seguridad desde receptor847@gmail.com. La autorización solicita el permiso de envío de Gmail (gmail.send) y los datos básicos de identidad necesarios para confirmar que se autorizó la cuenta remitente. Onta My Money no solicita permiso para leer, buscar ni administrar la bandeja de entrada.

El backend almacena el refresh token de Google cifrado con una clave separada administrada como secreto. Los destinatarios reciben el correo necesario para la función que solicitaron. Los tokens de verificación y recuperación son de un solo uso y caducan.

Almacenamiento, uso y conservación

Los datos financieros permanecen en el almacenamiento local del dispositivo para uso sin conexión y se sincronizan con la cuenta autenticada cuando hay conexión. Las operaciones pendientes se conservan hasta que puedan sincronizarse. Los datos enviados a la nube se usan para prestar y proteger el servicio, resolver sincronización entre dispositivos y responder a solicitudes del usuario.

Los mensajes operativos no se usan para publicidad. La aplicación no vende datos personales. Google procesa las solicitudes de envío de acuerdo con sus términos y políticas de privacidad.

Seguridad y control

Las sesiones de la aplicación usan tokens de acceso de corta duración y refresh tokens rotativos. El usuario puede cerrar sesiones desde la aplicación. El administrador puede revocar el acceso de Gmail desde la configuración de su cuenta de Google; si eso ocurre, el servicio de correo debe volver a autorizarse.

Contacto y cambios

Para consultas sobre privacidad, escribí a receptor847@gmail.com. Esta política debe actualizarse si cambian los datos tratados, los proveedores o los plazos de conservación. Última actualización: 6 de noviembre de 2026.
